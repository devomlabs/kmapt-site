앱에서 직접 삭제하기

  1. 앱에 로그인합니다.
  2. 하단 메뉴의 마이페이지로 이동합니다.
  3. 계정 > 회원 탈퇴를 누릅니다.
  4. 안내를 읽고, 본인 확인을 위해 다시 로그인한 뒤, 확인 문구("회원탈퇴")를 입력하면 바로 탈퇴됩니다.

탈퇴는 즉시 처리되며 취소할 수 없어요. 내가 쓴 글과 댓글은 자동으로 지워지지 않으니, 지우고 싶다면 탈퇴 전에 먼저 삭제해 주세요. 탈퇴 화면에서 내가 쓴 글·댓글 개수와 바로가기를 볼 수 있습니다.

앱을 쓸 수 없을 때 이메일로 요청하기

앱을 지웠거나 로그인할 수 없다면 가입한 이메일 주소로 {{support_email}} 에 "계정 삭제 요청"이라고 보내 주세요. 본인 확인 후 영업일 기준 7일 안에 처리하고 결과를 알려 드립니다. 이용 정지 중인 계정도 이메일로 요청해 주세요.

게시글·댓글·투표·좋아요자동 삭제되지 않음. 탈퇴 시 닉네임이 새로 발급되어 작성자를 알아볼 수 없게 됩니다.
재가입 제한용 이메일 해시값탈퇴일부터 3일간 보관 후 자동 삭제 (이메일 원문이 아닌 해시값)
